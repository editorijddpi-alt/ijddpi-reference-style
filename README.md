# IJDDPI Reference Style

Citation Style Language (CSL) style for the **International Journal of Drug Discovery and Pharmaceutical Innovation (IJDDPI)**.

**Journal abbreviation:** *Int. J. Drug Discov. Pharm. Innov.*

## About

This repository provides the Citation Style Language (CSL) style for the **International Journal of Drug Discovery and Pharmaceutical Innovation (IJDDPI)**.

The style follows **Vancouver-style numeric referencing conventions** and is intended for use with CSL-compatible reference management software.

## Citation Style

- **Citation system:** Numeric
- **In-text citation:** [1], [2], [3]
- **Reference order:** Order of citation
- **Authors:** Up to six authors are listed; for seven or more authors, the first six are followed by *et al.*
- **Journal titles:** Abbreviated journal titles
- **DOI:** Presented as `https://doi.org/...`
- **Page ranges:** Full page ranges are retained

## Using the Style

The `ijddpi.csl` file can be used with reference management software that supports Citation Style Language (CSL).

Compatible applications include:

- Zotero
- Mendeley
- Juris-M
- Other CSL-compatible reference managers

## Installation

### Zotero

1. Download the `ijddpi.csl` file from this repository.
2. Open Zotero.
3. Go to **Edit → Settings → Cite → Styles**.
4. Click the **+** button.
5. Select `ijddpi.csl`.
6. The IJDDPI style will then be available for citation and bibliography formatting.
